# Well Done

You just practiced the complete package-management workflow that every future tool install will follow:

- **Refreshed** the catalog first — and saw why a stale index is the real cause behind `Unable to locate package` on fresh machines.
- **Installed** `htop` and `tree` with apt and recorded version evidence, instead of downloading mystery binaries from websites.
- **Used** the tools immediately: a live process view and a directory outline.
- **Inspected** package metadata and dependencies — the queryable evidence engineers reach for when two machines disagree.

The same pattern — refresh, inspect, install from a trusted source, verify — is exactly what you will do for `kubectl`, `helm`, and `kind`. Only the package names get bigger.
